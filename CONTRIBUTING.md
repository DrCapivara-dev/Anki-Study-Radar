# Contributing

Thanks for helping improve **Anki Study Radar**.

For bug reports, please include:

- Anki Desktop version.
- Operating system.
- Study Radar version.
- What you expected to happen.
- What actually happened.
- Error message or screenshot, if available.

For feature suggestions, describe the study problem you want the feature to solve.

Please do not include private Anki collection data, personal information, or copyrighted study material in public issues.

Code contributions should be discussed with the project owner before substantial work is started, because this repository is source-available rather than open-source.
