# Anki Study Radar

Use **Ferramentas → Study Radar** para abrir o painel principal.

As configurações comuns são editadas pela interface gráfica. A aba **Pro** leva à central de compra e ativação.

A partir da v1.2.0, o Study Radar está conectado ao backend oficial em `https://study-radar-backend.onrender.com`. O add-on cria o checkout do Mercado Pago pelo backend, acompanha o status da compra e ativa a licença automaticamente.

A configuração JSON continua disponível para usuários avançados. Não altere `license_api_url` salvo se estiver usando um servidor próprio compatível.
