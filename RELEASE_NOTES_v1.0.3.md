## Anki Study Radar v1.0.3

### UI spacing fix
- Fixed the three secondary action buttons looking glued together or overlapping on some Anki layouts.
- **Abrir** remains the centered primary action.
- **Revisão**, **Adiar** and **Ocultar** now have clear, consistent spacing and balanced widths.
- Added CSS safeguards against inherited Anki button margins.

### Preserved
- Clean v1.0.2 dashboard header.
- Automatic cleanup of completed temporary filtered decks.
- Quick Review, Focus Session, Analytics, Exam Mode and licensing foundation.

### Installation
Install `Anki_Study_Radar_v1.0.3.ankiaddon` over the previous version and restart Anki.

The private OWNER key from v1.0.0 remains valid.
