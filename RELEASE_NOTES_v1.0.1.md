## Anki Study Radar v1.0.1

### What's new
- Automatic cleanup of completed Quick Review / Focus Session filtered decks.
- Empty Study Radar temporary sessions can be cleaned automatically on Anki startup.
- New manual cleanup command under **Tools**.
- New cleanup controls in **Study Radar — Configurações → Geral**.
- Safety guard: cleanup only targets empty filtered decks created with the Study Radar temporary-deck prefix. Normal decks and cards are not deleted.

### Why this update
Temporary filtered decks no longer need to accumulate in the user's deck list after a Study Radar session is completed.

### Installation
Install `Anki_Study_Radar_v1.0.1.ankiaddon` over the previous version and restart Anki.

### Compatibility note
The private OWNER key from v1.0.0 remains valid in v1.0.1. Do not publish the OWNER key.
