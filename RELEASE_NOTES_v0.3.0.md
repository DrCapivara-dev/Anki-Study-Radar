# Anki Study Radar v0.3.0 — Public Beta

This release adds **Smart Review / Revisão Rápida**.

## New
- ⚡ Quick Review button on each recommendation.
- Automatically selects the most problematic reviewed cards.
- Prioritizes recent Again/Hard answers and historical lapses.
- Builds a short preview filtered deck, preserving normal FSRS scheduling.
- Quick Review size is configurable (default: 25 cards).
- Priority score is now visible in the Radar.
- Dedicated Quick Review settings tab.

## Notes
This is still a beta release. Please report your Anki version and a screenshot/error message if Quick Review fails to build a filtered deck.
