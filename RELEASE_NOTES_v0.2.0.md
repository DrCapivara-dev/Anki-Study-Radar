# Anki Study Radar v0.2.0 — Public Beta

This release adds a friendly graphical settings panel, so users no longer need to edit JSON manually.

## New

- **Tools → Study Radar Settings...** menu entry.
- **⚙ Settings** button inside the Radar.
- Easy controls for:
  - thematic review intervals;
  - history window;
  - maximum decks shown;
  - minimum reviews required for a meaningful session;
  - upcoming-review window.
- **Restore defaults** button.

The add-on still does **not** modify FSRS or individual card scheduling.
