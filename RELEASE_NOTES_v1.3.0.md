# Anki Study Radar v1.3.0

## Account System
- Create/login with email + password inside Anki.
- Purchases are linked to the connected Study Radar account.
- PRO Lifetime supports **1 active device at a time**.
- Existing Pro accounts can activate a new PC after deactivating the old one.
- Passwords are not stored in the add-on.
- Change password, sign out, verify Pro and deactivate this PC from the central account window.
- SR-PRO key recovery remains available for support.
- OWNER key remains compatible and private.

## Installation
Install `Anki_Study_Radar_v1.3.0.ankiaddon` over the previous version and restart Anki Desktop.

## Backend requirement
Commercial account features require Study Radar Backend v1.1.0 or newer.
