# Anki Study Radar v1.1.2

## Analytics Free + Pro

This release makes Analytics part of the Study Radar experience for **every user**.

### Free
- Analytics button is always visible.
- Basic overview: tracked topics, attention items, approximate retention and 7-day review load.
- Basic focus ranking and 7-day forecast charts.
- Built-in **Analytics Pro preview** with a visual example of the complete dashboard.
- Clear **Ativar Pro** action and list of advanced features.

### Pro / Owner / Tester
- Full Analytics dashboard remains available.
- Visão geral, Desempenho, Baralhos and Insights.
- Advanced retention, answer distribution, interval consolidation, card types, weak-point analysis and study recommendations.

### Compatibility
Includes the v1.1.1 Qt/PyQt 6.9 chart drawing hotfix.

Commercial checkout is still under development; the OWNER test license continues to work as before.
