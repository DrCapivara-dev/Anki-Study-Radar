## Anki Study Radar v1.0.2

### Cleaner daily dashboard
- **Abrir** is now the main action for every recommended deck and is centered in a full-width primary row.
- **Revisão**, **Adiar** and **Ocultar** now sit together below it as secondary actions.
- The home header is more compact and less visually noisy.
- Removed the explanatory “O Radar organiza temas sem substituir o FSRS” sentence from the dashboard.
- Replaced the previous priority header with a lighter **Em foco** line.
- The “temas para revisar hoje” count is intentionally smaller and more discreet.

### Preserved from v1.0.1
- Automatic cleanup of completed Study Radar temporary filtered decks.
- Optional cleanup of empty temporary sessions on Anki startup.
- Quick Review, Focus Session, Analytics, Exam Mode and licensing foundation remain unchanged.

### Installation
Install `Anki_Study_Radar_v1.0.2.ankiaddon` over the previous version and restart Anki.

### Compatibility note
The private OWNER key from v1.0.0 remains valid in v1.0.2. Do not publish the OWNER key.
