# Anki Study Radar v1.0.4

## Cleaner Tools menu

This release removes the clutter caused by multiple Study Radar entries in Anki's **Tools** menu.

### What's changed
- **Tools → Study Radar** is now the only Study Radar menu entry.
- Clicking it opens a central control panel.
- The panel contains:
  - ⚙ Configurações
  - ⭐ Licença / Pro
  - ⏱ Sessão Foco
  - 📊 Analytics
  - 🧹 Limpar sessões vazias
  - 🩺 Diagnóstico
- The Add-ons window **Config** button still opens Study Radar settings directly.
- No changes to the Radar recommendation algorithm, Smart Review, FSRS behavior, temporary-deck cleanup, or license compatibility.

## Installation
Install `Anki_Study_Radar_v1.0.4.ankiaddon` over the previous version and restart Anki.
