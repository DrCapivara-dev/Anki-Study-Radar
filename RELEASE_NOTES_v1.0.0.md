## Anki Study Radar v1.0.0

This release consolidates Study Radar into its first 1.0 architecture.

### New
- ⭐ Study Radar Pro foundation
- ⏱ Focus Session based on available study time
- 📊 Advanced deck analytics
- 🎯 Exam Mode
- 🔑 OWNER / TESTER / PRO license roles
- ⏰ Snooze recommendations
- 🙈 Ignore and re-enable decks
- 🧭 Built-in diagnostics
- 🎚 Review interval presets

### Existing features retained
- Deck-level review recommendations
- Priority score
- Again / Hard analysis
- Quick Review / Smart Review
- Friendly settings window
- Clean hierarchical deck names

### Installation
Download `Anki_Study_Radar_v1.0.0.ankiaddon` below and install with:

**Anki → Tools → Add-ons → Install from file**

### Status
v1.0.0 is the first consolidated release, but the commercial Mercado Pago license backend is still being connected. OWNER testing is available privately.
