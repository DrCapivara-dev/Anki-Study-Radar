# Anki Study Radar v1.2.1

## License key visibility

This release fixes the Pro purchase experience so customers can actually keep the license they purchased.

### New
- New **Sua licença** section in the Pro hub.
- **Mostrar chave** securely retrieves the license for the currently activated device.
- **Copiar chave** copies the `SR-PRO-...` key to the clipboard.
- A key generated by a just-approved purchase is displayed immediately after automatic activation.
- Manual commercial activations also display the key for easy reuse on the second allowed device.

### Security
The reusable commercial key is not permanently stored in plaintext by the add-on. On later sessions it is requested from the backend using the already-valid activation token. OWNER remains offline/private.

### Requirement
Deploy **Study Radar Backend v1.0.4 or newer** before relying on `Mostrar chave` after restarting Anki.
