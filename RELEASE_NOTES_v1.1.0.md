# Anki Study Radar v1.1.0

## 📊 Analytics Pro Dashboard

This release turns Analytics from a basic table into a visual study-decision dashboard.

### New
- Summary cards for topics, attention, approximate retention, streak, upcoming workload and estimated study time.
- **Where to focus** priority chart.
- **7-day review forecast** chart.
- **14-day study activity** chart.
- Again / Hard / Good / Easy donut chart.
- Weekly retention trend.
- Interval consolidation analysis.
- Card-type distribution.
- Expanded detailed deck analytics table.
- **Insights** tab with:
  - best next step;
  - suggested daily plan;
  - weak-point detection;
  - workload warning;
  - performance trend;
  - direct Smart Review and 30-minute Focus Session actions.

### Safety / scheduling
Study Radar continues to use preview-mode filtered decks for Smart Review and Focus Session, keeping normal Anki/FSRS scheduling intact.

### Status
v1.1.0 is a major feature update. Feedback and bug reports are welcome.
